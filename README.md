# Evently — Premium 3D-inspired redesign

A dependency-light, GitHub Pages-ready front-end for Evently.

## Deploy

1. Create or open your GitHub repository.
2. Replace the existing `index.html` with this file.
3. Commit and push to the branch used by GitHub Pages.
4. In **Settings → Pages**, choose **Deploy from a branch**, select your branch and `/root`.

## Included interactions

- Responsive premium UI with floating cards, glassmorphism, 3D-inspired event scene, hover depth and motion.
- Smooth navigation and rotating/scrollable event categories.
- Functional quote modal with validation and request preparation.
- Copy-request action using the browser clipboard when available.
- Mobile responsive layout and reduced-motion support.
- Light/dark appearance toggle.

The quote form is front-end only. Connect it to Formspree, Netlify Forms, a serverless function, or your own backend for real enquiry delivery.
